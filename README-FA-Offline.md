# نسخه آفلاین TasksWebApp

این نسخه هیچ فایل CSS/JavaScript/فونتی را از CDN یا سایت خارجی بارگذاری نمی‌کند. فایل‌های رابط کاربری زیر در `wwwroot/lib/offline` قرار دارند:
- CSS سازگار با کلاس‌های استفاده‌شده در صفحات برنامه
- اسکریپت محلی باز/بسته‌کردن منوی موبایل
- جایگزین‌های آفلاین آیکون‌ها
- فونت محلی Noto Sans Arabic برای نمایش فارسی در حالت آفلاین

## اجرا
۱. پروژه را در Visual Studio باز کنید.
۲. در صورت نیاز پکیج‌های NuGet را قبلاً Restore کنید؛ برای ساخت روی رایانه کاملاً آفلاین، پکیج‌ها باید از قبل در NuGet cache موجود باشند.
۳. Build و سپس اجرا کنید.

## یادداشت فونت
فایل واقعی Vazirmatn در محیط تهیه این بسته موجود نبود. برای اینکه برنامه بدون اینترنت فونت فارسی داشته باشد، Noto Sans Arabic به‌صورت محلی همراه بسته شده است. اگر فایل‌های Vazirmatn (`.woff2` یا `.ttf`) را ارائه کنید، می‌توان آن‌ها را جایگزین فونت محلی کرد تا خود Vazirmatn نیز کاملاً آفلاین باشد.
