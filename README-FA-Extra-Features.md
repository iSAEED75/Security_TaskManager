# امکانات تکمیلی سامانه TasksWebApp

## امکانات اضافه‌شده
- تاریخچه فعالیت‌ها: ثبت ایجاد/ویرایش وظیفه، تغییر وضعیت، ستاره‌دارکردن، تبدیل به گزارش، حذف نرم، پیگیری، پیوست، پشتیبان‌گیری و بازیابی.
- سطل بازیافت: حذف مدیر به‌صورت حذف نرم انجام می‌شود؛ مدیر می‌تواند مورد و زیر‌وظیفه‌های حذف‌شده را بازیابی یا برای همیشه حذف کند.
- پیگیری و پیوست: هر وظیفه/گزارش صفحه اختصاصی برای یادداشت‌های پیگیری و فایل‌های PDF، تصویر، DOCX، XLSX، TXT و CSV دارد. حجم هر فایل حداکثر ۱۰ مگابایت است و فایل‌ها بیرون از wwwroot نگهداری می‌شوند.
- عملکرد کارکنان: آمار وظایف واگذارشده، تکمیل‌شده، عقب‌افتاده، ساعات کار و تعداد گزارش‌ها همراه با خروجی Excel.
- پشتیبان‌گیری: از منوی مدیر یک ZIP شامل اطلاعات سامانه و فایل‌های پیوست دریافت کنید. اطلاعات گذرواژه کاربران در فایل نیست. بازیابی اطلاعات را به داده‌های فعلی اضافه می‌کند و جایگزین/پاک‌کننده اطلاعات موجود نیست.

## ارتقای پایگاه داده
در زمان راه‌اندازی، DbSeeder ستون‌های حذف نرم و جدول‌های تاریخچه، پیگیری و پیوست را به شکل افزایشی ایجاد می‌کند. قبل از اجرای نسخه جدید روی داده‌های واقعی، از پایگاه داده SQL Server نسخه پشتیبان بگیرید.

## امنیت و محدودیت‌ها
- صفحات مدیریتی با نقش Admin در سمت سرور محافظت می‌شوند.
- پیوست‌ها در مسیر App_Data/TaskAttachments قرار دارند و فقط از طریق handler احراز هویت‌شده قابل دریافت هستند.
- برای محیط عملیاتی، مسیر ذخیره پیوست‌ها را روی دیسک امن با مجوز دسترسی محدود نگه دارید و پشتیبان‌های ZIP را در مکان محافظت‌شده ذخیره کنید.
- فایل پروژه در محیطی بدون ابزار .NET SDK و SQL Server بررسی شده است؛ پس از استخراج، ابتدا Rebuild Solution را در Visual Studio انجام دهید و روی یک کپی از پایگاه داده آزمایش کنید.
