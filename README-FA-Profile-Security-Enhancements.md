# امکانات پروفایل و امنیت حساب

## امکانات افزوده‌شده
- ویرایش نام و نام خانوادگی از پروفایل؛ نام کاربری و شماره پرسنلی در این مسیر قابل تغییر نیستند.
- ثبت نشست‌ها در جدول `UserSessions` و اعتبارسنجی سمت سرور کوکی در هر درخواست احراز هویت‌شده؛ خاتمه نشست‌های دیگر و بی‌اعتبارسازی نشست در درخواست بعدی آن دستگاه.
- پرچم `MustChangePassword` برای حساب‌های موقت؛ مسیرهای سامانه تا تغییر گذرواژه محدود می‌شوند.
- ثبت آخرین ورود موفق، آخرین تلاش ناموفق و تعداد تلاش‌های ناموفق از آخرین ورود موفق؛ رخدادهای ورود در تاریخچه فعالیت‌ها ثبت می‌شوند.
- صفحه مدیریت کاربران برای ایجاد حساب با گذرواژه موقت تصادفی و بازنشانی گذرواژه. گذرواژه قبلی هرگز نمایش یا ثبت نمی‌شود؛ مقدار موقت جدید فقط یک‌بار در پاسخ عملیات نمایش داده می‌شود و پس از ورود باید عوض شود.
- خلاصه عملکرد شخصی شامل تعداد وظایف، تعداد گزارش‌های کار و مجموع ساعات گزارش‌شده بر اساس موارد ثبت‌شده توسط همان کاربر.

## ارتقای پایگاه داده
در شروع برنامه، `DbSeeder` ستون‌های جدید را به‌شکل افزایشی می‌افزاید و جدول `UserSessions` را در صورت نبود ایجاد می‌کند. دستورات برای SQL Server هستند و داده‌های موجود را حذف نمی‌کنند. با این حال، پیش از اولین اجرا در محیط واقعی، از پایگاه داده نسخه پشتیبان بگیرید و روی یک کپی آزمایشی ابتدا راه‌اندازی را بررسی کنید.

## حساب پیش‌فرض
اگر پایگاه داده تازه باشد، حساب پیش‌فرض `admin` با گذرواژه اولیه `Admin@1234` الزاماً باید گذرواژه را تغییر دهد. برای پایگاه داده قدیمی نیز در صورت باقی‌بودن همین گذرواژه، هنگام ورود پرچم تغییر اجباری فعال می‌شود. از نگهداری این گذرواژه در محیط عملیاتی خودداری کنید.

## نکات عملیاتی
- پوشه `App_Data/ProfilePhotos` و پوشه‌های پشتیبان باید برای هویت اجرای برنامه مجوز نوشتن محدود و کافی داشته باشند.
- برای جلوگیری از قفل‌شدن مدیر، بازنشانی گذرواژه حساب مدیرِ واردشده از همان حساب مجاز نیست؛ حساب مدیر دیگری باید آن را بازنشانی کند.
- اعتبار نشست‌ها با پایگاه داده بررسی می‌شود. در محیط چندنمونه‌ای، همه نمونه‌ها باید به همین پایگاه داده متصل باشند.
- گزارش ساعات از جمع `DurationHours` موارد `WorkReport` غیرحذف‌شده‌ای محاسبه می‌شود که `CreatedById` آن‌ها متعلق به کاربر جاری است.
- اعتبارسنجی کامپایل و اجرای واقعی این نسخه در این محیط ممکن نبود، زیرا ابزار `dotnet` نصب نیست. پس از دریافت ZIP، در Visual Studio با .NET 8 و SQL Server تست کنید.
