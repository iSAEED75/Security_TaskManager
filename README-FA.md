# سامانه ثبت گزارش کار

سامانه تحت وب برای ثبت، جست‌وجو، ویرایش و مدیریت گزارش فعالیت‌های روزانه با ASP.NET Core Razor Pages و SQL Server.

## امکانات
- ثبت گزارش با عنوان، شرح فعالیت، تاریخ انجام، مدت زمان صرف‌شده، دسته‌بندی، وضعیت پیگیری و اهمیت.
- مشاهده و جست‌وجوی گزارش‌های کاربر؛ مدیر سامانه امکان مشاهده گزارش‌های همه کاربران را دارد.
- صفحه آمار شامل تعداد گزارش‌ها، مجموع ساعات کار و تفکیک بر اساس وضعیت، اهمیت و دسته‌بندی.
- دریافت گزارش‌ها در قالب فایل Excel با عنوان‌ها و وضعیت‌های فارسی.
- رابط کاربری راست‌چین و فارسی.
- ارتقای خودکار پایگاه داده موجود برای افزودن تاریخ فعالیت و مدت زمان، بدون حذف گزارش‌های قبلی.

## اجرای پروژه
1. نصب .NET 8 SDK و SQL Server.
2. تنظیم `DefaultConnection` در `appsettings.json` متناسب با SQL Server.
3. باز کردن `TasksWebApp.sln` در Visual Studio.
4. اجرای `dotnet restore` و سپس `dotnet build` و `dotnet run` در پوشه پروژه.

## حساب مدیر اولیه
در صورتی که پایگاه داده خالی باشد، حساب مدیر با نام کاربری `admin` و گذرواژه `Admin@1234` ساخته می‌شود. پیش از استفاده واقعی، گذرواژه را تغییر دهید و ثبت‌نام عمومی را متناسب با سیاست سازمان بررسی کنید.

## نکته سازگاری پایگاه داده
در اولین اجرای این نسخه، ستون‌های `WorkDate` و `DurationHours` در جدول موجود `TaskItems` ایجاد می‌شوند. داده‌های قبلی حفظ می‌شوند و تاریخ فعالیت گزارش‌های قدیمی از تاریخ ثبت قبلی پر می‌شود.


## قابلیت‌های نسخه جدید
- هنگام ثبت، می‌توانید بین «ثبت گزارش کار» و «ثبت وظیفه برای انجام دادن» انتخاب کنید.
- تاریخ در فرم‌ها و فهرست‌ها با تقویم شمسی نمایش داده می‌شود؛ تاریخ را به صورت سال/ماه/روز مانند ۱۴۰۵/۰۱/۰۱ وارد کنید.
- ستون نوع ثبت به صورت خودکار به پایگاه داده‌های قبلی اضافه می‌شود و اطلاعات قبلی حفظ می‌شوند.
